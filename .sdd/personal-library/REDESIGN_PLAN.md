## 1. 三张参考图分析（各取什么）

| 参考 | 关键特征 | 本次借鉴 |
|---|---|---|
| **Obsidian（图1）** | 最左 ~40px 图标条（ribbon）；文件树侧栏；编辑区多标签页；图谱视图是一等公民面板；右侧大纲栏；浅色底 + **紫色仅用于链接/强调**；图谱节点深灰、连线浅灰、背景纯白 | 整体骨架：ribbon + 侧栏 + 主区 + 右栏四段式；单一强调色原则（v0.9 用雾蓝，见 §2）。注：Obsidian 的图谱仅作参考，v0.9 已砍掉图谱功能（第五轮） |
| **Notion（图2）** | 暖米白页面底（约 `#F6F4EF`），白色应用卡片大圆角浮在其上；窄侧栏树形导航 + emoji 图标；内容列约 720px 居中；H2 带 1px 下划线；几乎无阴影无渐变，1px 分割线 | 色彩基调（暖白纸感）；设置页与问答页的窄列排版；H2 下划线、callout、列表 hover 等组件语汇 |
| **Typora（图3）** | 极窄顶栏（文件名居中、状态角标）；左侧 180-200px 大纲/文件树；主体就是一篇安静排版的文档；无多余 chrome | 问答视图的阅读感：对话即文档，正文 15-16px、行高 1.7、引用角标如脚注；顶栏做到最窄（36px） |

**三图交集（= 设计原则）**：
1. **内容第一，chrome 消隐**——工具本身几乎不可见，分割线代替卡片边框。
2. **一个强调色**——雾蓝 `#8B9FAD` 只给链接、活动态、引用角标；其余全部灰阶。（08-31 审核修订：弃紫，改用你指定的雾蓝）
3. **多面板并行**——信息密度靠面板承载，不靠弹窗和浮层。
4. **动效克制**——三家几乎没有动效；动效只用于面板开合、视图淡切。

## 2. 设计语言规范（v0.9 tokens）

### 色彩（浅色 = 默认，参考 Notion 暖白 + 用户指定雾蓝）

| Token | 值 | 用途 |
|---|---|---|
| `--bg-frame` | `#F6F4EF` | 应用外框底（Notion 米白） |
| `--bg-pane` | `#FFFFFF` | 侧栏/主区/右栏面板底 |
| `--bg-hover` | `#F1F0EB` | 列表 hover、按钮 hover |
| `--divider` | `#E9E8E3` | 全部 1px 分割线（代替卡片边框） |
| `--text-1` | `#37352F` | 主文字（Notion 墨色） |
| `--text-2` | `#787774` | 次级文字、时间、说明 |
| `--text-3` | `#B4B2AD` | 占位、禁用 |
| `--accent` | `#8B9FAD` | 唯一强调色（雾蓝/蓝灰，08-31 你指定）：活动视图图标、指示条、开关 |
| `--accent-text` | `#5F6C76` | 小字号文字场景（链接、引用角标、按钮与活动项文字）——雾蓝加深，白底对比 ≈5:1 |
| `--accent-weak` | `#EFF2F4` | 活动项底色、选中底 |

深色主题保留（Obsidian 也有深色）：`--bg-frame #1E1E1E`、`--bg-pane #262626`、`--text-1 #DCDDDE`、强调色提亮为 `#A5B4BF`（--accent-text 深色下用 `#C3CDD5`），其余同构。**无渐变、无毛玻璃、无阴影**（仅抽屉/菜单浮层允许一层 `0 4px 16px rgba(0,0,0,.08)`）。

### 字体与排版

- 系统栈：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`；代码/路径/引用编号用 `ui-monospace`。
- 页面标题 22px/600；视图内 H1 30px（问答空态 34px）；正文 15px / 行高 1.7；侧栏与列表 13.5-14px；顶栏 13px。
- 图标（08-31 审核修订：弃 emoji）：**Lucide 风格线性图标**——24px 网格、1.8px 描边、圆角端点、`currentColor` 单色随文字变色；以 SVG `<symbol>` sprite 内联复用，16 / 18 / 20 三档尺寸；不引外部图标库（零 CDN 原则）。线框图已换装可预览。

### 尺寸

- Ribbon 44px ｜ 侧栏 232px（随视图切换内容；可折叠到 0，记忆状态）｜ 右栏 264px（仅问答视图，默认折叠，回答开始自动展开）｜ 顶栏 36px ｜ 内容最大列宽 720px（问答/设置），文档预览 780px。

## 4. 各视图线框与交互

（下面是文字版，可视化版看 `wireframes.html`）

### 4.1 问答视图（默认落地视图；08-31 第六轮修订：文档式直接书写，无输入框）

主区 = **一篇可写的文档**（contenteditable，720px 窄列，Typora 式）：

```
（空白文档态）                                （已写入态）
│                                              │
│  在文档里直接写下你的问题…▏                     │  说明书B.pdf 里的保修政策是什么？   ← 问题块（加粗墨色）
│                                              │  ▎根据说明书 B…整机保修 24 个月[1]…  ← 回答块（左侧雾蓝细线，流式）
│  像写文档一样打字 · 连续两次 ⏎ 发送 · 单次 ⏎ 换行   │  ▏                                ← 光标落回底部
│                                              │    继续往下写 = 继续追问，两次 ⏎ 再次发送
│                                              │                  （生成中 · Esc 停止）← 右下角浮动 pill
```

- **直接书写**：没有输入框——切到问答即光标就位，像 Typora 一样直接打字写问题。
- **两次回车 = 发送**：单次 ⏎ 正常换行；连续两次 ⏎（间隔 <600ms，或在空行上按 ⏎）把上方文字作为问题发送：该段转为加粗"问题块"，下方立即流式插入"回答块"（左侧雾蓝细线、正文排版、内嵌引用角标 [n]）。
- **续写即追问**：回答完成后光标落回文档底部，继续写下一段、再两次 ⏎ 又发一轮——**同一对话就是同一篇文档**，与侧栏"最近对话"一一对应（标题=首问）。
- **AI 生成中动画（08-31 第八轮）**：发送后回答块文字前方显示**粒子线圈动画**（Originkit OrbCoil 移植：canvas 2d 零依赖、雾蓝 #A5B4BF、24px、呼吸线圈 + 流动，参数用其内置 preset）——生成完成自动隐藏；生成中右下角同时浮"生成中 · Esc 停止"pill；Esc 或点击打断，已生成部分保留，光标可在其后继续编辑重写。
- **引用联动**：角标 hover 高亮右栏对应卡片；右栏卡片点击 → 正文定位/打开文档。回答开始时右栏自动展开，结束后可手动收起。
- **对话历史**：每次发送自动保存（标题=首问截断，含全部问答块与引用），侧栏点击恢复整篇文档继续写；存 localStorage，上限 50 条（跨设备同步=后端 threads 表，见 §8）。
- **移动端**：同文档式书写，键盘连按两次回车发送；"引用 N 条"折叠在回答末尾可展开。
- 实现要点：contenteditable 编辑器 + Enter 键监听（双击判定/空行判定）→ 发送段标 `data-role="q"`，回答插入 `data-role="a"` 流式填充；编辑器内不做富文本（纯段落，粘贴转纯文本）。
