它是怎么画出来的

没有 GIF、没有视频、没有 WebGL — 每一帧都是 150 次三角函数计算 + 150 个圆点，五步管线：

STEP 1

生成球面螺旋

150 个粒子沿参数 u ∈ [0,1) 分布，极角 θ=πu 从北极走到南极，形成一条绕球面的螺旋线。

STEP 2

圈数呼吸

螺旋圈数 turns(t) 在 2 → 8 之间以余弦节奏往复，线圈不断缠紧、松开。

STEP 3

整体旋转 + 滑动

方位角随时间匀速旋转（一周期整一圈），同时所有粒子沿螺旋线滑动（u+t）。

STEP 4

透视投影

固定视角（pitch −45°），透视除法 3.5/(3.5−z)：近的点更大更亮，远处的更小更淡。

STEP 5

画家算法绘制

按深度 z 排序，远的先画、近的后画，逐点 arc + fill 叠加成半透明雾蓝粒子云。

数学拆解

逐帧几何 100% 由以下四个公式决定（t 为周期相位 0→1）：

① 球面螺旋 — 粒子坐标

u  = (i/150 + t) mod 1        // 沿线滑动
θ  = π·u                       // 北极 → 南极
az = 2π·(u·turns(t) + t)       // 缠绕 + 整体旋转
p  = (cos(az)·sin θ,  cos θ,  sin(az)·sin θ)

单条螺旋线采 150 个点；密度权重 f = sin(πu)^0.45 让赤道带更粗、两极更细。

② 圈数呼吸 — 动画的“心跳”

turns(t) = 2 + 6·(0.5 − 0.5·cos(2πt))   ∈ [2, 8]

t=0 时仅绕 2 圈（最疏），t=0.5 时 8 圈（最密）。这是动画“呼吸感”的唯一来源。

③ 透视与深度衰减

s     = 3.5 / (3.5 − z)                    // 透视
depth = clamp((z + 1.1) / 2.2, 0, 1)
半径  = 0.4 + 1.6·depth·s·(0.6+0.9f)      // 近大远小
α     = (0.07 + 0.93·depth^1.55)·f       // 近实远虚

α 最深只有 0.07（几乎消失），最近接近 1 — 前后层次全靠这两个公式拉开。

④ 视角与自动缩放

预旋转   spin(yaw=0.3, pitch=0.36)
观察     yaw=5°, pitch=−45°   // 斜俯视
autoFit = clamp(0.415·size/ext, 0.55, 1.7)
         = 1.7（本例触顶）     // 20 探针求包围盒
周期    = 6 / 1.92 = 3.125 s

autoFit 防止 8 圈最密时粒子溢出画布；本例直接顶到上限 1.7。

turns(t) 呼吸曲线（一周期）

t=0.25 → 5 圈 · t=0.5 → 8 圈（峰值） · t=0.75 → 5 圈 · 回到 2 圈闭合循环。纵轴 2–8。

帧是怎么导出的

没有重写算法：_tools/capture-orb.js 把 ai-orb.js 的几何函数逐行静态复制（标注源码行号），以 phase = k/188 步进计算每帧全部绘制点；_tools/render-frames.py 用 PIL + numpy 按 source-over 合成渲染成带 1px 抗锯齿边缘的透明 PNG；最后 ffmpeg 合成 60 fps APNG。

node    _tools/capture-orb.js          # frames.json：188 帧 × 每帧约 150 个点 (x, y, r, α)
python  _tools/render-frames.py        # frames/f000.png … f187.png（480×480 RGBA）
ffmpeg -framerate 60 -i frames/f%03d.png -f apng -plays 0 orb-60fps.apng
